## Modern Ukrainian bakery - landing page sample

This is the part of learning process - Landing page

Use please graphic redactor [Figma](https://www.figma.com/downloads/)

For the references the right code-guidance is on the site
[Code Guide for html/css](https://codeguide.co/)

To check the teg nesting we can go to
[caninclude](https://caninclude.onrender.com/)

The validity of html-file can be cheked
[W3C Validator](https://validator.w3.org/#validate_by_uri)

To switch the local fonts we use
[google-webfonts-helper](https://gwfh.mranftl.com/fonts)

To optimize all images for the layout can be on [Squoosh](https://squoosh.app/)

For SVG-sprite the sprite generetor was used on site https://icomoon.io/

To optimize svg-icons the site can be used https://svgomg.net/

To compile scss I use VS Code extention "Live Sass Compiler"

I tried to use here the ARIA (Accessible Rich Internet Applications) attributes:
• Tell assistive technologies (like screen readers) what a component is and what
state it’s in. For example, common ones for menus: 1 aria-label → gives a
descriptive name. 2 aria-controls → links a button to the element it toggles. 3
aria-expanded → communicates whether the menu is open or closed. 4 aria-modal →
indicates that focus is trapped inside a modal/dialog.

To create the slider I used [Swiper](https://swiperjs.com/get-started)
